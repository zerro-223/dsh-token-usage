This fix is superseded by v1.0.1, published just now.

The missing cacheWrite billing was implemented in 1.0.1 with a dedicated per-model `cacheWrite` price column (modelradar.cn provides `cacheWritePricePer1M` for 90 models, e.g. Anthropic), instead of approximating cache writes at the input price — the two agree when no cache-write price is set, but the dedicated field is more accurate where providers price cache writes separately.

The rest of this PR's findings match the shipped code: reasoning tokens are folded into output tokens and not billed separately, and the pure cost functions are being extracted to `lib/cost.js` with a `node:test` suite in the repo (adapting this PR's test cases to the cacheWrite-price implementation).
